04 Algorithm

19 criteria. One cost function. Many possible compromises.

Candidate allocations are scored using a weighted cost function. Lower is better. The engine combines a greedy initial construction with local-search moves and swaps, then keeps the best result across repeated attempts.

06 What's next

Built locally. Thinking increasingly in cloud systems.

The local filesystem architecture is intentional for a single-school deployment. For a multi-school version, the natural next step would be managed storage, a job queue, stronger isolation and containerised deployment.

The architectural direction

Database-backed state → job queue → isolated workers → container deployment → centralised logs and backups.
